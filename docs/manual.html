ASampler 1.0 Manual

ASampler is an MPC-style drum and chop sampler for Windows and macOS, designed first for producers who use a screen reader. This manual is written to be read with one. Every section and subsection is a heading, so heading navigation (H, or 1 to 3 for heading levels, in NVDA and JAWS browse mode) jumps between them, and the parameter reference uses tables with header cells.

1. What ASampler is

ASampler has 32 pads in two banks of 16, like an MPC: bank A is pads 1 to 16, bank B is pads 17 to 32. Each pad holds a sample (or up to eight, as layers) and plays it when it receives its MIDI note. Pads can be drums that fire on a single note, or melodic instruments spread across the keyboard. Every pad has its own envelope, filter, lo-fi character, two LFOs, mod wheel routing, glide, tempo sync, time stretch, formant control, stereo width and output.

The design rule behind ASampler is that everything you can change is a host parameter. That means the whole instrument can be read and controlled from REAPER's parameter list, automated, and mapped to hardware, without any custom screen to learn. The editor window adds a keyboard-driven pad grid and actions such as loading, chopping and bouncing, and every result is spoken.

2. Installing

Windows

  1. Run ASampler-1.0.0-Windows-Setup.exe. It is a standard installer that NVDA and JAWS read normally.
  2. If Windows SmartScreen says "Windows protected your PC", choose More info, then Run anyway. The installer is not yet code-signed.
  3. The installer puts the plugin in C:\Program Files\Common Files\VST3\ASampler.vst3 and adds this manual to the Start menu.
  4. If you have used REAPER on this computer, the installer offers a checkbox, checked by default: Add the "Create pad tracks" action to REAPER's Actions list. Leave it checked and the routing script (section 16) is ready to use in REAPER's Actions list as "Script: ASampler - Create pad tracks.lua", with nothing to load by hand. REAPER must be closed while this happens; if it is open, the installer asks you to close it and choose Retry.
  5. In REAPER, if ASampler doesn't appear in the FX browser, open Options, Preferences, Plug-ins, VST, then choose Re-scan.

macOS

The Mac version is built automatically and passes the same tests as the Windows one, but nobody has tried it on a real Mac yet. If you do, please report how it went, especially with VoiceOver, on the project's GitHub Issues page.

  1. Run ASampler-1.0.0-macOS.pkg. It installs the VST3 to /Library/Audio/Plug-Ins/VST3 and the Audio Unit to /Library/Audio/Plug-Ins/Components. It works on macOS 11 or later, on Apple Silicon and Intel.
  2. The package isn't signed by Apple, so macOS blocks it the first time. In Finder, open the context menu on the package (with VoiceOver, Control+Option+Shift+M), choose Open, then confirm.
  3. If your DAW still says the plugin is damaged or won't load it, run this in Terminal:
    sudo xattr -dr com.apple.quarantine /Library/Audio/Plug-Ins/VST3/ASampler.vst3 /Library/Audio/Plug-Ins/Components/ASampler.component
  4. On a Mac, press Cmd wherever this manual says Ctrl.

Uninstalling

On Windows, use Settings, Apps, ASampler, Uninstall. It also removes the routing script and its entry in REAPER's Actions list, along with any shortcut key you gave it, so nothing is left pointing at a missing file. Close REAPER first; the uninstaller asks if it is open. On macOS, delete the two files listed above.

3. Quick start: your first beat

  1. In REAPER, insert a new track, add ASampler to it, and arm the track for recording with monitoring on.
  2. Open the ASampler window and press Tab until you reach the pad grid. You hear "Pad 1, default, note C1, key Z". Before you load anything, every pad plays a built-in test tone.
  3. Press L to open the file dialog, choose a kick drum, and press Enter. You hear "Loaded kick.wav into Pad 1 (Layer 1)".
  4. Press Space to hear it. Press N to try the next file in the same folder, and P to go back.
  5. Press Right Arrow to move to Pad 2 and load a closed hi-hat, then Pad 3 for an open hi-hat, and Pad 5 (one row up) for a snare.
  6. To make the open hat stop when the closed hat plays, open REAPER's parameter list for ASampler. Set Focused Pad to Pad 2 and Focus Choke Group to Group 1, then Focused Pad to Pad 3 and Focus Choke Group to Group 1. Alternatively, choose Factory kit, then Trap, which does this and more without changing your samples.
  7. Play the pads from a MIDI keyboard, or from the computer keyboard with Z X C V for pads 1 to 4 and A S D F for pads 5 to 8. Pads use notes C1 upwards (MIDI 36 to 51 for bank A), the General MIDI drum notes, so REAPER's drum maps and most drum MIDI files line up straight away.
  8. Save your REAPER project. Your samples and all settings are saved with it.

4. Setting up REAPER

  • Let the editor have your keys. With the ASampler window focused, open the FX window's context menu (Applications key) and turn on "Send all keyboard input to plug-in". Without it, REAPER keeps Space, letters and arrows for its own actions.
  • The parameter list. OSARA's parameter dialog (in the FX chain, press P) lists every ASampler parameter, and you can type a value into it. REAPER's own FX parameter list and envelope menus show the same parameters.
  • Automation. Any parameter can be automated: show its envelope from the track's envelope list, then write or draw it as usual.
  • Separate outputs. Run the "ASampler: Create pad tracks" script. See section 16.
  • Presets. REAPER's preset menu for ASampler lists the four factory kits (see section 17). REAPER's own preset saving also works and stores everything.

5. Screen readers and speech

When something happens that you didn't move focus to, such as a sample finishing loading, a chop completing or an error, ASampler speaks a message. On Windows it sends the message through Windows UI Automation notifications, so your screen reader speaks it in its own voice, at its own rate, and you can review it in speech history.

Screen reader support
Screen readerStatus
NVDA 2021.1 or laterMessages spoken automatically.
JAWS 2021 or laterMessages spoken automatically. If you hear nothing, check that notifications aren't turned off in JAWS settings for REAPER.
NarratorMessages spoken automatically.
VoiceOver (macOS)Messages are sent as VoiceOver announcements. Not yet tried on a real Mac.

How messages behave:

  • An identical message isn't repeated, so a burst of the same event is spoken once.
  • Errors interrupt current speech. Routine confirmations wait their turn.
  • The last message is always in the status line at the bottom of the editor. Tab to it to read it again.

6. The editor

The editor is in five parts. Tab moves between them in this order:

  1. Heading: "ASampler 1.0.0".
  2. Pad grid, one Tab stop.
  3. Pad actions: buttons for the selected pad.
  4. Kit actions: buttons for the whole instrument.
  5. Status line: the last message.

The pad grid

The grid shows one bank of 16 pads, laid out like an MPC: Pad 1 bottom left, Pad 4 bottom right, Pad 13 top left, Pad 16 top right. Bank B uses the same positions for pads 17 to 32. Inside the grid:

  • Arrow keys move between pads. Up goes to higher pad numbers, and up from the top row of bank A carries on into bank B (up from Pad 13 is Pad 17).
  • Page Up and Page Down switch bank and keep your place: Pad 5 becomes Pad 21. They work from anywhere in the editor. You hear "Bank B, pads 17 to 32". The Bank button above the grid does the same.
  • Home and End jump to Pad 1 and Pad 32.
  • Moving onto a pad selects it. The Focused Pad parameter follows, so the host's Focus group now controls that pad too.
  • Space or Enter plays the pad.
  • Ctrl and a pad number jumps straight to that pad when you let go of Ctrl: hold Ctrl, type 1 then 2, release, and you are on Pad 12, in whichever bank it is.

Each pad reads its number, its name if you gave it one, sample name, trigger, any mute or solo, and its computer key. For example: "Pad 3, open hat.wav, note D1, key C", or "Pad 1, Big 808, 808.wav, keys C0 to C3, root C1, key Z". F2 renames the selected pad; leave the name empty to remove it. Names are saved with the project, in kits, and travel with Copy and Paste.

Playing from the computer keyboard

The keys Z X C V, A S D F, Q W E R and 1 2 3 4 play the 16 pads of the current bank like a keyboard: the pad sounds while the key is held and stops when you let go, so one-shot drums play out and sustained sounds hold. Holding a key does not retrigger it. The velocity is the global Computer Key Velocity parameter (default 100).

The notes also go to ASampler's MIDI output. To record what you play: add a second track, give it a MIDI send from the ASampler track (in REAPER, a send with MIDI only), arm it for recording, and play. Only the computer keys are sent; MIDI arriving from REAPER is not echoed back out.

Hold Shift with a pad key to hear what that pad holds, without playing it: "Pad 2, Snare, snare 04.wav, note C#1, key X".

7. The parameter list and the Focus group

ASampler has about 4,800 parameters: 146 for each of 32 pads, plus globals. Three things keep that manageable.

The Focus group

At the top of the list, after the global parameters, is Focused Pad, then 146 parameters named "Focus Volume", "Focus Filter Cutoff" and so on. They always control the focused pad, and they read that pad's values. Change Focused Pad, or select a pad in the editor, and the whole Focus group switches to it. You can shape any pad without leaving the top of the list.

Pad prefixes

Each pad's own parameters start with its number: "P1 Volume", "P9 Filter Cutoff". Even in a flat list, the name tells you which pad it belongs to. Use these for automation that must always target the same pad.

Sections

Every pad, and the Focus group, is divided into the same sections, always in this order:

  1. Main
  2. Trigger
  3. Envelope
  4. Slice
  5. Filter
  6. Layers
  7. Repeat
  8. Pitch and Glide
  9. Character
  10. Modulation
  11. Time and Formant
  12. Stereo

Hosts that show parameter groups, such as REAPER's FX parameter menus, show these as submenus.

Typing values

Values are spoken with units, for example "-6.00 dB", "120 Hz", "C1", "1/16" or "250.0 ms". Where the host lets you type a value, as OSARA's parameter dialog does, you can type it the same way. For slice points, see section 9.

8. Loading, browsing and describing samples

Loading

L or the Load button opens the system's standard file dialog. Supported formats:

  • WAV, AIFF, FLAC, Ogg Vorbis and MP3

Files load in the background, so REAPER never freezes. You hear "Loading..." when it starts and the result when it finishes. The sample goes into the layer chosen by the global Edit Layer parameter (Layer 1 by default).

Other ways to load:

  • Drag and drop audio files from Explorer or Finder onto a pad.
  • Paste: copy files in Explorer (Ctrl+C), then press Ctrl+V in ASampler. They go to the selected pad.

Loading several files at once

Choose several files in the dialog (Ctrl or Shift with the arrow keys and Space), drop several, or paste several, and a menu asks where they go. Each choice says what it will replace:

  • One per pad: the files go onto the selected pad and the pads after it, in natural order ("kick 2" before "kick 10"). Files beyond Pad 32 are skipped, and you are told how many.
  • Round-robin layers: up to 8 files become the selected pad's layers, and Layer Mode is set to Round Robin. Any other layers on the pad are cleared.
  • Velocity layers: the same, with Layer Mode set to Velocity and the velocity range shared evenly, the first file softest.

All of it is one background load, one announcement and one undo step.

Trimming silence

Trim silence moves the pad's Start to just before the sound begins (where it comes within 30 dB of its peak) and its End to where it has died away (60 dB below the peak). It is measured on the current slice, changes no audio, and can be undone. Turn on the global Trim Silence On Load to do this automatically, over the whole sample, every time a sample is loaded.

Browsing

N and P load the next and previous audio file from the folder of the pad's current sample. Files are in natural order, so "kick 2" comes before "kick 10". The pad's settings stay as they are, and the pad plays the new sample at once, so you can step through a folder of kicks and hear each one in context. You hear the name and position, for example "kick 07.wav, 7 of 32". Browsing can be undone.

Trying samples before you keep them

Shift+N and Shift+P also step through the folder, but only try each file: the pad plays the candidate with all its settings, and its own sample stays underneath. This is the quickest way to pick the right kick.

  1. Select the pad and press Shift+N. You hear the next file on the pad and "Trying kick 08, 8 of 32. Enter keeps it, Escape goes back".
  2. Keep pressing Shift+N or Shift+P. Each candidate plays as you reach it.
  3. Press Enter to keep the one you are on, or Escape to go back to the pad's own sample.

Try it while the beat plays: with REAPER's transport running, the candidate is not auditioned on its own, it simply plays in the beat wherever the pad's notes are. On an empty pad, trying starts in the folder of the last sample you loaded.

Describe

I speaks a description of the pad's current slice, starting with the pad number and sample name. It covers:

  • Length of the current slice, where it sits in the whole sample, and how many bars it lasts at the project tempo.
  • Peak and RMS level: RMS is the average loudness.
  • Hits: the number of detected attacks.
  • Tempo, for loops. Use it to set Original BPM for tempo sync.
  • Key, for melodic material, or pitch, for single notes such as an 808. Use the pitch to set the root note. Noise and drums report no key rather than a guess.

Missing samples

ASampler stores where each sample was loaded from. If you move a project to another computer, or move your sample folder, it keeps the references and says how many are missing. Press Relink samples, choose the folder that now holds them, and they are found by file name, including in subfolders.

9. Slicing and audition

Each pad plays the region from Start to End of its sample. Both read as time into the sample, for example "1.250 s" or "480.0 ms". When typing a value you can use:

  • seconds: 1.25 or 1.25 s
  • milliseconds: 480 ms
  • a percentage of the sample: 50%

Audition On Edit is a global parameter, on by default. When you stop changing Start or End, ASampler plays the pad from the new point:

  • after a Start change, from Start
  • after an End change, from just before End, so you hear where it cuts off

This lets you place boundaries by ear. It never plays while REAPER's transport is running, so automation never triggers it.

Editing Start and End by ear

For fine placement, press T to edit Start or O to edit End (or the Edit Start and Edit End buttons). Then:

  • Right and Left (or Up and Down) move the point 10 ms later or earlier. With Ctrl the step is 1 ms, with Shift 100 ms. Home and End go to the start and end of the sample.
  • Each step speaks the new position and plays a short snippet. For Start you hear the first 80 ms from the point. For End you hear the 150 ms leading up to it backwards, so the first thing you hear is exactly where the sound is cut.
  • Space plays the snippet again.
  • Enter keeps the new point, as one undo step. Escape leaves it as it was.

Nothing changes until you press Enter, so you can explore freely.

Cleaning up boundaries:

  • Zero-Cross Snap moves Start, End and loop points to the nearest point where the waveform crosses zero, which removes clicks.
  • Snap to transients (button) moves Start and End onto the nearest detected hit. Use it when a chop landed slightly early or late.
  • Fade In and Fade Out add short fades at the edges of the slice.

Looping: set Loop Mode to Forward or Ping-Pong and the pad loops between Loop Start and Loop End while the note is held. Loop Crossfade smooths the join in Forward mode.

10. Chopping a loop across pads

  1. Load a loop onto any pad and select it.
  2. Set the global Chop Count to 2, 4, 8, 16 or 32 slices. 32 fills both banks.
  3. Set the global Chop Mode:
    • Equal cuts equal lengths, which suits a loop that is exactly in time.
    • Transients cuts at detected hits. Use it for drum breaks.
    • Transients (Spectral) also finds hits that change tone without getting louder, such as hi-hats under a kick.
  4. Press the Chop button. Its label says what it will replace, for example "Chop Pad 1 into 16, replacing pads 1 to 16".
  5. Each pad now plays one slice, in order. Use Snap to transients or Start and End to adjust any slice, and Undo if you don't like the result. The whole chop is one undo step.
  6. Press Export slice MIDI to write a MIDI file that plays the slices in their original order. Insert it into REAPER to rebuild the loop, then rearrange the notes.

11. Pads, notes and keyboard mode

Note names in ASampler use the convention where middle C (MIDI 60) is C3, the default in REAPER and most drum machines. Pads 1 to 16 default to notes C1 to D#2 (MIDI 36 to 51), and pads 17 to 32 carry on from E2 to G3 (MIDI 52 to 67).

Mode

  • Fixed (default): the pad plays on its one Note. Use it for drums.
  • Keyboard: the pad plays every note from Low Note to High Note, pitched relative to Note, which becomes the root. Use it for 808s, bass and melodic chops. Other pads can stay Fixed in the same kit, and one note never plays two things:
    • A Fixed pad with a sample loaded keeps its own note. The Keyboard pad skips that note.
    • A Fixed pad that still has only the built-in tone steps aside. The Keyboard pad plays that note instead.
    So if you have loaded drums on pads 1 to 8, notes C1 to G1 play the drums and every other note plays the Keyboard pad. To use the drum notes for the Keyboard pad too, move the drum pads' notes or put the melodic sound in its own ASampler instance.

Learning notes from a MIDI keyboard

Press K and play a note on your MIDI keyboard: it becomes the selected pad's Note (the root, in Keyboard mode). The Learn note button also offers Low Note and High Note, to set a Keyboard pad's range by playing its lowest and highest keys. The note you play to learn does not sound. Escape cancels. If you set Low Note above High Note, or the other way round, the other end moves with it so the range stays valid.

Scale Lock

Set the global Key and Scale, then turn on Scale Lock on a keyboard pad. Notes outside the scale snap to the nearest note in it, so a chop can't play off-key.

Choke groups

Pads with the same Choke Group stop each other. Put the closed and open hi-hats in one group and the open hat is cut when the closed hat plays.

Voices

Max Voices sets how many notes a pad can play at once (default 8). Set it to 1 for a monophonic pad: each new note cuts the previous one, and with Glide Mode on, slides from it. ASampler has 256 voices in total, enough for every pad to play 8 notes at once.

One Shot, Mute and Solo

  • One Shot plays the whole slice regardless of how long the note is held. Use it for drums.
  • Mute silences a pad.
  • Solo silences every pad that isn't soloed.

Muted pads keep playing silently, as in a mixer, so unmuting mid-note picks up where the sound would be.

12. Layers and multisampling

Each pad can hold eight samples, called layers. Choose which layer Load, Reset and Normalise act on with the global Edit Layer parameter. The pad's Layer Mode decides which layer plays:

Layer modes
ModeWhich layer playsTypical use
VelocityEach layer plays for velocities between its Vel Low and Vel High. Layers whose ranges overlap play together. A hit that no loaded layer covers plays the layer with the nearest range.A snare recorded at several strengths, or a kick stacked with a sub.
Round RobinEach hit plays the next layer in turn.Natural-sounding repeated hits, so a roll doesn't sound like a machine gun.
RandomA random layer each hit.Variation without a pattern.
Key ZonesEach layer covers its own note range (Layer N Low Note and High Note) and is pitched from its own Layer N Root Note. A note outside every zone uses the layer with the nearest root.A multisampled instrument: a bass or keys sampled every few notes, so no sample is stretched far from where it was recorded.

Layer N Gain balances the layers. Normalise sets it automatically.

Velocity ranges and stacking

By default Layers 1 to 4 split velocity into four bands (0 to 31, 32 to 63, 64 to 95, 96 to 127) and Layers 5 to 8 cover the whole range. Set Layer N Vel Low and Vel High to change them. Ranges may overlap: give a clap and a snare the same range and every hit plays both, which is how layered drums are built. The Spread velocity layers button shares 0 to 127 out evenly among the loaded layers, Layer 1 softest, and loading several files as velocity layers does the same. A stacked pad can sound Max Voices notes per layer, so stacking never cuts itself short.

Release layers

Set a layer's Trigger to Release and it plays when the note is let go instead of when it starts: a piano's damper noise, a string release, a vinyl stop. It plays once at the velocity of the original hit, and never loops. A release layer also responds to its velocity range.

Tuning each layer

Layer N Transpose (in semitones) and Fine Tune (in cents) retune one layer against the others, for example to tune a stacked sub to the kick.

13. Shaping the sound

Envelope

Attack, Decay, Sustain and Release shape volume over each note. The defaults (instant attack, full sustain, 50 ms release) play the sample as it is.

Filter

Filter Mode is Low-pass, High-pass or Band-pass, set with Filter Cutoff and Filter Resonance. The filter has its own envelope:

  • Filter Env Amount sets how far each hit sweeps the cutoff, in octaves, up or down.
  • Filter Env Attack, Decay, Sustain and Release shape the sweep.

A positive amount with a short decay gives the classic plucked bass sound.

Character

Character effects come after the filter, in this order:

  1. Saturation, with Saturation Mode:
    • Tube: warm, rounded
    • Tape: soft compression
    • Hard Fold: aggressive, metallic
  2. SR Reduce: lowers the sample rate, for aliasing grit like old samplers.
  3. Bit Depth: crushes the resolution; Off means full quality.

Pitch and glide

  • Pitch transposes the pad by up to two octaves, in fine steps.
  • Pitch Env Amount and Pitch Env Time start each note sharp or flat and slide it back. A few semitones over 30 to 80 ms gives an 808 or kick its punch.
  • Glide Mode slides between notes on a keyboard pad:
    • Legato: only while notes overlap
    • Always: on every note
    • The "(rate)" versions read Glide Time as milliseconds per semitone, so long jumps take longer, like a real slide.
  • Vel to Glide shortens the slide on harder notes, so you can control each glide from the piano roll.

Modulation

Each pad has two LFOs. Each one wobbles one destination: pitch, filter cutoff, volume or pan. Set Rate, Depth and Shape (Sine, Triangle, Square or Saw). When both LFOs move the same destination, their effects add up. Use one for a slow filter sweep and the other for a fast wobble, or vibrato on pitch while the first LFO moves the filter.

LFO Sync and LFO 2 Sync lock an LFO to the project tempo. Choose a note length, from 4 bars down to 1/32, including triplets and dotted values. One LFO cycle then lasts exactly that long, and the Rate in Hz is ignored. Off uses the Rate.

The mod wheel (MIDI CC 1) can move one destination per pad. Set Mod Wheel Destination and Mod Wheel Amount:

  • Pitch, Filter Cutoff, Volume and Pan use the same ranges as the LFO. A negative amount works in reverse: with Volume at -100%, pushing the wheel up fades the pad out.
  • LFO 1 Depth and LFO 2 Depth add the wheel to that LFO's depth. Route an LFO to Pitch at 0% depth, send the wheel to its depth, and the wheel brings in vibrato.

The wheel moves notes that are already playing, and it is smoothed, so it doesn't step or click.

Velocity can do more than set volume:

  • Vel to Cutoff opens the filter on harder hits, by up to 4 octaves.
  • Vel to Pitch raises or lowers pitch with velocity.
  • Vel to Start starts harder hits later into the sample, skipping more of the attack.

Velocity Curve shapes how velocity sets volume:

  • Soft: quiet hits are louder
  • Linear
  • Hard: more effort for full volume
  • Fixed: every hit at full volume

Stereo

  • Stereo Width goes from Mono through Normal to 200%.
  • Mono Below makes everything under the chosen frequency mono, which keeps 808s and bass solid on club systems and phones.

Pan places the pad left or right.

Live changes

Changing a parameter while a note is held affects that note immediately, so you can hear what you are adjusting.

14. Tempo sync, time stretch and formant

Tempo sync

Turn on Tempo Sync and set Original BPM to the loop's tempo. Describe (I) estimates it. The pad now follows the project tempo. Stretch Mode chooses how:

  • Repitch (default) speeds the sample up or down like a turntable or an MPC, so pitch moves with tempo. It uses no extra CPU.
  • Stretch changes length but keeps the original pitch, so a 90 BPM riff fits an 80 BPM beat in the same key.

Formant

Formant shifts the character of a sound, its "body" or vocal size, without changing its pitch:

  • negative values give a bigger, deeper voice
  • positive values give a smaller, brighter one

Formant Correct (keyboard pads only) keeps the sample's natural character as you play it up and down the keyboard, so a vocal or bass doesn't chipmunk at high notes or turn muddy at low ones.

Speed

Speed plays the sample faster or slower without changing its pitch: +100% is twice as fast, -100% half speed. It works in any Stretch Mode and combines with tempo sync.

Keep Length

On a Keyboard pad, higher notes normally play shorter, as on a tape machine. Keep Length makes every note last as long as the root, so a vocal phrase or a loop stays in time across the keyboard. Turn on Formant Correct as well to keep the voice natural. Like Formant Correct, it prepares one version per semitone in the background.

How processing works

Stretching and formant shifting are rendered in the background whenever these settings or the project tempo change, and the pad then plays the processed copy. Playback costs no extra CPU. A render starts within a tenth of a second of a change and is quick: a 10-second stereo loop takes about 0.1 to 0.2 seconds. Several pads render at the same time on separate processor cores, Formant Correct renders its per-note versions side by side, and if you keep turning a knob, renders you have already moved past are stopped. Until a render finishes, the pad plays the previous result, or the unprocessed sample the first time. The status line says when it is ready, and the Render stretch and Render formants buttons finish it immediately.

The stretch engine keeps stereo intact: the two channels are processed together, so the stereo image and the mono sum come out as they went in.

15. Note repeat, swing and humanize

Turn on a pad's Repeat and, while you hold its note, the pad retriggers at the Repeat Rate, synced to the project tempo. Rates run from 1/4 to 1/32 triplet.

  • Swing delays every second repeat, for a shuffled feel.
  • Humanize adds small random changes to timing and velocity.

Use it for trap hi-hat rolls: hold the note and play with Repeat Rate, or automate it.

16. Separate outputs and the REAPER routing script

ASampler has a main stereo output plus one stereo output per pad. By default everything plays through the main output. When a pad's own output is connected in the host, that pad plays there instead, so it can have its own fader, effects and stem.

The routing script

The "ASampler: Create pad tracks" script does all the REAPER routing for you. The Windows installer copies it into REAPER's Scripts folder. On a Mac, take it from the scripts folder of the project on GitHub and load it once as described below.

  1. Find the action: open the Actions list (?) and type "pad tracks" in the filter. On Windows the installer has already added it, as "Script: ASampler - Create pad tracks.lua". You can give it a keyboard shortcut in the same list. If it is not there (on a Mac, or if you unchecked the installer's box), load it once: choose New action, then Load ReaScript, and pick ASampler - Create pad tracks.lua. The installer always leaves a copy in the REAPER folder next to this manual.
  2. Select the track with ASampler on it. If only one track has ASampler, you don't need to select it.
  3. Run the action. It asks how many pads to route; press Enter for 16 (bank A), type 32 for both banks, or type a smaller number, for example 4 for pads 1 to 4 only.
  4. The script adds that many tracks, named "ASampler Pad 1", "ASampler Pad 2" and so on, directly below the ASampler track. It sends each pad's output to its track and widens the ASampler track to carry the extra channels. OSARA speaks the result. The whole action is one undo step.

Pads you didn't route keep playing on the ASampler track. Running the script again only adds what is missing, so you can route 4 pads now and the rest later.

Doing it by hand

  1. Set the ASampler track to 2 channels plus 2 per pad you want to route, up to 66 channels for all 32 pads, in its routing window.
  2. Make sure ASampler's output pins are connected one to one, in the plugin pin connector.
  3. Add a send from the ASampler track to each new track. Pad 1 uses source channels 3 and 4, Pad 2 uses 5 and 6, and so on up to Pad 32 on 65 and 66.

REAPER extras

  • Ctrl+R in the editor toggles REAPER's record, without leaving the plugin window.
  • Ctrl+G, or the Grab REAPER item button, puts the one selected item in REAPER onto the selected pad as you hear it: fades, volume, playback rate and take effects included. ASampler glues a copy, takes the result, and undoes the glue, so your project is left as it was. The file is kept in %APPDATA%\ASampler\grabbed. Select exactly one item first; you are told if none or several are selected.

These work only when ASampler runs inside REAPER. In other hosts they say so.

17. Kits, factory kits and programs

Saving and loading kits

Save kit (Ctrl+S) stores everything in a .asamplerkit file; Load kit (Ctrl+O) opens one. REAPER projects already save all of this, so kits are for reusing a setup across projects. Saving asks which kind of kit to make:

  • Kit with sample paths: all parameters, pad names, and where each sample is.
  • Kit with copies of its samples: the same, and every sample is copied into a folder next to the kit, named after it ("Trap kit samples"). Move or share the kit file together with that folder and it still finds its samples, on any computer.
  • Template: settings only. Loading a template changes every parameter and leaves your samples and pad names alone, like a factory kit.

Factory kits

The four factory kits set up a playing style and never change your samples.

Every factory kit first sets up the following on all pads:

  • one-shot drums with short fades and Zero-Cross Snap
  • pads 2 and 3 as the closed and open hi-hat in choke group 1

Then each kit adds its own settings:

18. Copy, paste, bounce, normalise, MIDI export

  • Copy and Paste: select a pad and press Copy, select another and press Paste. All settings, samples and the pad's name are copied. Use it to build variations of a sound.
  • Apply settings to other pads: the button opens a menu. Choose To all 32 pads or To this bank, then a section, then one setting (each shows the selected pad's value) or the whole section. For example, give every pad in the bank the same Release, or the whole Envelope section of this pad. The result says how many pads changed, and it is one undo step.
  • Bounce (B) renders the selected pad to a new WAV file, with every setting applied: slice, envelope, filter, character, stretch and formant. It loads the result onto the next empty pad, so you can commit a sound and keep building on it, or resample. Bounces are saved in your ASampler bounces folder (%APPDATA%\ASampler\bounces on Windows) and stay available to the project.
  • Normalise sets the layer's gain so it peaks at -1 dB. It doesn't change the file and can be undone.
  • Export slice MIDI writes a .mid file with one note per pad slice, in order. You choose where to save it.

19. MIDI learn and controllers

  1. Set the global MIDI Learn parameter to Armed.
  2. Touch the parameter you want to control, in REAPER's parameter list or by moving its automation.
  3. Move a knob or fader on your MIDI controller. ASampler binds that controller (CC) to the parameter and disarms.

Bindings are saved with the project and with kits. Learning a controller that is already bound moves it to the new parameter. You can also use REAPER's own Learn and parameter modulation, which work with every ASampler parameter.

Pitch Bend Range sets how far the pitch wheel bends every sounding pad, from 1 to 24 semitones (default 2).

20. Undo and redo

Every parameter change and every action can be undone with Ctrl+Z (or the Undo button), and redone with Ctrl+Y. Undoable actions include loading, browsing, chopping, pasting, applying settings to pads, trimming, editing Start and End by ear, learning notes, factory kits, normalising and clear all. A chop across 32 pads is one step. Selecting pads is not recorded, so walking the pad grid never fills the history. Loading a project starts a fresh history.

21. Recipes

A gliding 808

  1. Load an 808 onto a pad. Press I; Describe tells you its pitch, for example "pitch F0".
  2. Set Mode to Keyboard, Note to that pitch, Low Note to C0 and High Note to C3. Notes that other pads use (C#1 to D#2 by default) keep playing those pads, so for the full range put the 808 in its own ASampler instance.
  3. Set Max Voices to 1 and Glide Mode to Legato, with Glide Time 60 to 120 ms.
  4. Add punch with Pitch Env Amount +3 to +5 semitones and Pitch Env Time 40 ms.
  5. Set Mono Below to 120 Hz. Make sure One Shot is off, so notes end when released, and set Release to around 300 ms.
  6. Play overlapping notes to slide. Turn on Formant Correct if the 808 sounds thin at high notes.

Hi-hats with rolls

  1. Closed hat on Pad 2 and open hat on Pad 3, both in Choke Group 1.
  2. On Pad 2, turn on Repeat, set Repeat Rate to 1/16, and add Humanize 10 to 20%.
  3. Hold the note and automate Repeat Rate to 1/32 or 1/16T for rolls.

Fitting a sample loop to your tempo

  1. Load the loop, press I, and note the tempo.
  2. Turn on Tempo Sync and set Original BPM to that tempo.
  3. For the MPC sound, leave Stretch Mode on Repitch. To keep the key, choose Stretch.
  4. Chop it across pads if you want to rearrange it (section 10).

A playable vocal chop

  1. Load a vocal phrase, set Start and End around one syllable, and listen with Audition On Edit.
  2. Set Mode to Keyboard, turn on Scale Lock, and set the global Key and Scale to your song's.
  3. Turn on Formant Correct so the voice stays natural across the keyboard, or use Formant to change its character.
  4. Bounce it to commit the result if you want to layer or chop it further.

A dusty lo-fi kit

Choose Factory kit, then Lo-Fi, then fine-tune Saturation, Bit Depth and SR Reduce per pad in the Character section. A slow, shallow LFO on Pitch (0.3 Hz, 3%) adds tape wobble.

24. Troubleshooting

Space or letters control REAPER instead of ASampler.
Turn on "Send all keyboard input to plug-in" in the FX window's context menu.
I hear no spoken messages.
The status line at the bottom of the editor always has the last message. Check that your screen reader version supports UI Automation notifications (section 5).
A pad is silent.
Select it and press I. Possible causes:
  • It is muted, or another pad is soloed.
  • Its sample is missing; use Relink.
  • Its Start is at or after its End.
  • Its Note doesn't match what you are playing.
  • Its output is routed to a pad track whose send was removed.
A pad's sound is on its own track and I want it back on the main output.
Remove that pad's send from the ASampler track, or set the track back to 2 channels.
A stretched pad sounds unchanged.
The render may still be running; press Render stretch. Also check that Tempo Sync is on, Stretch Mode is Stretch, and Original BPM differs from the project tempo.
Formant Correct says the job is too large.
Correction prepares one version per semitone of range. Narrow the pad's Low Note to High Note range, use Key Zones, or use a shorter sample.
The Mac says the plugin is damaged, or the DAW doesn't list it.
Run the xattr command in section 2, then rescan plug-ins in the DAW.
Grab REAPER item or Ctrl+R says it works only in REAPER.
ASampler talks to REAPER through its VST3 interface. Use the VST3 version, inside REAPER.
Playing pads from the computer keys records nothing.
The notes leave on ASampler's MIDI output. The recording track needs a MIDI send from the ASampler track, and must be armed.
The routing script says ASampler has only 2 output channels.
Use the VST3 version of ASampler. VST3 provides the per-pad outputs in REAPER.

25. Technical details

  • Formats: VST3 for Windows 10 or later, 64-bit. VST3 and Audio Unit for macOS 11 or later, Apple Silicon and Intel (not yet tried on a real Mac).
  • Pads: 32 in two banks of 16, with 8 layers each and 256 voices in total.
  • MIDI output: notes played on the computer keys.
  • Outputs: main stereo plus 32 stereo pad outputs (66 channels).
  • Pitching: pads pitched more than about 2 semitones above the sample's own pitch are read through a band-limited (windowed-sinc) filter that follows the pitch, so high frequencies are filtered out instead of folding back down as harsh aliasing. At or below the original pitch, playback uses cubic interpolation, which is cheaper and has nothing to fold.
  • CPU: 256 voices at the original pitch use about 32% of one core at 44.1 kHz (about 0.13% per voice). A voice pitched an octave up costs about 0.35%. Stretch and formant processing happens in the background and costs nothing during playback.
  • Sample rates: any. Samples are converted on the fly, and the stretch engine adapts its analysis to the sample's rate.
  • Saved state: every parameter, sample locations (kept even when missing), pad names and MIDI learn bindings, in the project or a .asamplerkit file.
  • Validation: every release passes pluginval at its strictest level, plus about 350 automated tests.
